# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, assume good faith, critique ideas rather than people, and keep discussions focused on the work.

Report unacceptable behavior privately to the maintainer through [GitHub's private reporting](https://github.com/vidithsalla/corrobo/security/advisories/new) or by contacting [@vidithsalla](https://github.com/vidithsalla) on GitHub. Reports are handled confidentially, and the maintainer may remove, edit or reject comments, commits, issues and pull requests that don't follow this code.
